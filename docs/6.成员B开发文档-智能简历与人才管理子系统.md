## 0. 当前基线（摘要）

- **服务**：`resume-service`（8084，`recruit_resume`）、`file-service`（8087，`recruit_file`）、`ai-service`（FastAPI，9010，`recruit_ai`）、`ai-worker`（8001，BGE/FunASR）、`mineru-worker`（8002，MinerU）；ES `resume_vec`。
- **AI 主档**：DeepSeek flash（`deepseek-chat`，云 API）优先 → 本地 Ollama（`qwen2.5:7b`，跑在**开发电脑**）兜底 → Mock；vLLM 可选。
- **对象存储**：file-service 统一封装 MinIO；resume-service 通过 `/internal/files/**` 访问，不直接依赖 MinIO。
- **迁移**：resume/file 用 Flyway；ai-service 用 SQLAlchemy + Alembic。
- **响应码**：`code=="0"` 为成功（已与总文档对齐）。
- **本地开发**：minimal/slim 档；平台后续部署到 VM，Ollama 不随 VM 部署。

## 2. 建议阅读/开发顺序

1. **01-overview** → 确认 B 的范围和与 A/C 的边界；
2. **02-architecture** → 理解上传/解析/检索/匹配/去重/人才库；
3. **03-services** → 确定各服务要写哪些模块；

5. **05-api** → 冻结 OpenAPI + DTO；
6. **06-events** → 落 Outbox/消费者；
7. **07-ai-rules** → 实现解析/匹配/去重等算法；
8. **08-local-dev** → 用 Mock 档跑通，再切真实档；
9. **09-milestones / 10-risks-tasks** → 排期、验收、勾任务。
