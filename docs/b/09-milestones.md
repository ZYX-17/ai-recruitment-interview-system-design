## 9. 里程碑（B）

| 周次 | B 的任务 | 阶段验收 |
|---|---|---|
| W1 | 云端 LLM API 冒烟（DeepSeek/通义）+ 本地 OpenAI 兼容兜底（vLLM/Ollama）+ guided JSON；FunASR 并发压测；MinerU 样例解析；ES kNN 冒烟；本文档定稿 | spike 结果与设备/版本记录 |

| W7~8 | ai-worker FunASR 字幕链路 | 与 C 联调；容量契约 |
| W9~10 | ai-service 收口：匹配双路/纪要/评价草稿/Prompt/审计/降级 | 匹配 TopK 初测；AI 故障不阻断 |

| W12 | 向量去重/合并审核/人才跟进提醒 | 同人 3 份合并；异人不误合并 |
| W13 | 评测集与指标：F1/Top5/NDCG/CER/消融 | 评测报告 |
| W14 | MQ 堆积/重试/故障注入；API 压测 | 容量报告 |
| W15~16 | 演示数据、离线包、缺陷修复 | 一键启动/拔网线演练 |

## 10. 验收指标

| 项 | 口径 |
|---|---|
| 简历解析 | PDF/Word/图片各 ≥3 份，≥90% 成功；表格保留行列；失败可重试 |
| 实体抽取 F1 | ≥85% |
| 匹配 Top5 命中率 | ≥80% |
| NDCG | 需报告/曲线（文档未给阈值） |
| 消融对比 | 随机 / 时间序 / 纯向量 / 双路 |
| ASR CER | ≤0.15（W1 POC 门槛） |
| 纪要覆盖率 | ≥80%（架构文档） |
| 匹配证据 | 五维逐项证据 + 缺口；可解释、可覆盖 |
| 查重合并 | 同人 3 份合并 1 档案；高相似异人不误合并 |
| 检索 | 关键词/向量/混合可用；ES 挂切 mysql-like |
| AI 故障 | 停 ai-worker/vLLM/ES，主业务继续；任务可重试/降级 |
| 性能 | HTTP P95 <300~500ms；ASR 冒烟 10 路全量，基线 40 路按 20 路契约 |
