## 六、登记规则

1. 新增文件时先在本清单登记（文件名 + Owner + 触发周次），再动手创建；
2. "按需"档触发时升级为"必现"并更新排期表；
3. 与 Flyway 相关的 SQL 一律从本文件夹 `sql/` 派生，禁止两处手改产生分叉；
4. 本清单每周五集成日（打 tag 时）核对一次，已落地文件移入对应服务仓库并在清单中打勾标记。
